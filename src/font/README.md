# 폰트

게임은 **Mona** 비트맵(픽셀) 폰트를 쓴다.

```
src/font/*.ttf          원본. 합계 30MB — git 에서 제외한다 (.gitignore)
src/font/subset/*.woff2 게임이 쓰는 서브셋. 228KB — git 에 커밋된다
```

## 왜 서브셋인가

배포본은 단일 HTML 한 장이고 목표 크기는 2MB 이하다.
원본 TTF 30MB 를 base64 로 넣으면 40MB 가 되어 불가능하다.

`scripts/subset-font.py` 가 **한글 음절 11,172자 전부 + ASCII + 기호**만 남기고
woff2 로 압축한다. 결과가 Mona10 112KB + Mona12 115KB.

쓰는 글자만 넣으면 20KB 까지 줄지만 그렇게 하지 않는다.
`content/*.json` 을 고쳐 새 문구를 넣는 것이 이 프로젝트의 기능이므로,
그 순간 두부(□)가 뜨면 안 된다.

## 다시 만들기

원본 TTF 를 `src/font/` 에 두고:

```bash
pip install fonttools brotli
python scripts/subset-font.py
npm run build
```

## 왜 두 벌인가 (Mona10 / Mona12)

비트맵 폰트는 **설계 크기와 그 정수배에서만** 선명하다.
11px·13px 로 그리면 브라우저가 외곽선을 보간해 뭉개진다 (실측 확인).

그래서 `src/core/font.js` 의 **크기 사다리**가 코드가 요청한 크기를
가장 가까운 선명한 크기로 스냅한다.

| 요청 | 실제 |
|---|---|
| 9 ~ 11 | Mona10 @ 10px |
| 12 ~ 17 | Mona12 @ 12px |
| 18 ~ 25 | Mona10 @ 20px (2배) |
| 26 ~ 33 | Mona12 @ 24px (2배) |
| 34 ~ 45 | Mona10 @ 40px (4배) |
| 46 ~ | Mona12 @ 48px (4배) |

사다리는 `content/ui.ko.json` 의 `font.ladder` 로 통째로 갈아끼울 수 있다.

## 이진화는 껐다

이전에는 시스템 폰트를 알파 이진화해서 도트처럼 보이게 했다.
진짜 픽셀 폰트에는 이 처리가 오히려 획을 깨뜨린다 (실측 확인).
`ui.ko.json` 의 `font.binarize: false` 가 이를 끈다.

비교 도구: `npm run serve` 후 `http://localhost:5173/scripts/fonttest.html`

## Mona 에 없거나 깨지는 기호

cmap 에 있어도 **글리프가 통짜 사각형**인 것이 있다. 아래는 실측으로 걸러낸 목록이다.

| 쓰지 말 것 | 이유 | 대신 |
|---|---|---|
| `▶` `◀` | 글리프가 통짜 사각형 | `→` `←` (정상) |
| `▣` | 폰트에 없음 | `■` |
| `①②③④` | 폰트에 없음 | `1)` `2)` … |
| `？` (전각) | 폰트에 없음 | `?` |
| `⏱` | Mona10 에 없음 (Mona12 에만 있음) | 아이콘 없이 숫자만 |

정상 확인된 기호: `◆ ■ □ ● ○ ★ ☆ ← → ↑ ↓ ↻ ↺ ✓ ✗ ☐ ⚠ × 「」 … · ♪ ▲ ▼`

새 기호를 쓸 때는 `scripts/subset-font.py` 의 목록에 추가하고 다시 만든 뒤,
실제로 그려보고 통짜 사각형이 아닌지 눈으로 확인할 것.

## 라이선스

Mona 폰트의 재배포·임베딩 조건을 확인할 것.
